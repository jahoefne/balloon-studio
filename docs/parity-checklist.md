- Plan §6: file input plus a drop overlay with the Mac panel’s message instead of NSOpenPanel.
- Plan §6: the web has no Finder; the line names the file, “saved” (File System Access) or “downloaded” (blob).
- Plan §7: bundled OFL fonts replace the Apple fonts behind the same names.
